# 🐶 TinDog Website

TinDog is a simple and responsive landing page for a dog dating app.  
The idea of this project is like Tinder, but for dogs. Users can discover nearby dogs, view app features, check pricing plans, and download the app.

This project is built using **HTML**, **CSS**, and **Bootstrap**.

---

## 📌 Project Preview

TinDog includes a clean modern layout with:

- Navigation bar
- Hero section
- Download buttons
- Feature section
- Testimonial section
- Press/logo section
- Pricing cards
- Call-to-action section
- Footer

## 📄 Files Explanation

### `index.html`

This is the main file of the website.  
It contains all the website structure like sections, text, buttons, images, cards, and links.

### `css.css`

This file contains the website design.  
It controls colors, spacing, font sizes, image sizes, backgrounds, and responsive styles.

### `images/`

This folder contains all images used in the website.  
All website pictures should be placed inside this folder to keep the project clean.

## ▶️ How To Run The Project

You do not need any server to run this project.

Just follow these steps:

1. Download or open the project folder.
2. Make sure all images are inside the `images` folder.
3. Open `index.html`.
4. The website will open in your browser.

---

## ⚠️ Important Notes

Make sure your image paths are correct.

Correct example:

```html
<img src="images/dog.png" alt="Dog image">
```

Wrong example:

```html
<img src="dog.png" alt="Dog image">
```

Use `images/dog.png` only when the image is inside the `images` folder.

Also make sure your CSS file is connected like this:

```html
<link rel="stylesheet" href="css.css">
```
